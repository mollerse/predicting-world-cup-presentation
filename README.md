# Predicting the World Cup

## Abstract

[NO]
Det er sommer, det er verdensmesterskap i fotball for menn, og Norge er med for første gang på veldig mange år. Spørsmålet alle sitter med; «Har vi sjans?» Det spørsmålet bestemte vi (Visuelle HIstorier i NRK) oss for å se om det var mulig å gi et slags svar på.

Løsningen vi endte opp med ble «VM Sjansen». En enkel statistisk modell for fotballkamper, innsikt fra kloke fotballeksperter og litt kode, og plutselig kunne vi svare på mer enn bare om Norge har sjans. Hvilket lag England mest sannynlig møter i 16.-finale? Hvor langt kan egentlig Haiti nå? Kan Sverige nå kvartfinale? Får vi et gigantoppgjør i åttendedelsfinale?

Bli med under panseret og inn på bakrommet. Hvordan ble dette implementert? Likte folk det? Klarte vi å spå VM i fotball?
